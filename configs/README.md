# Environments

- [bulkformer-latest.yaml](bulkformer-latest.yaml): Dedicated inference and Jupyter environment for the latest checkpoint. Environment name: `bulkformer-latest`.
- [../bulkformer.yaml](../bulkformer.yaml): Original model-family environment retained at its established path.

Architecture parameters for the latest checkpoint are supplied by its downloaded `model_config.json`. The original scale selector is `model/config.py`. See the [usage guide](../docs/usage.md).
